turnike

A turnstile for your APIs. Every request below is real, served by this instance and decided by a single Lua script inside redis.

Press Send to fire concurrent requests.
Response headers appear here.
Identity is the X-API-Key header — change it above and the budget is yours alone. Requests without one fall back to the caller's address, which behind a platform proxy is the proxy itself, so every keyless visitor would share one bucket. X-Forwarded-For is deliberately not trusted. Source & design notes.
